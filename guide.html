01产品概述

1.1这是什么

小青账 HTML 版是一款纯前端、单文件的个人记账工具，功能结构参考了移动端应用「小青账」， 用一份 HTML 文件重新实现。双击文件用浏览器打开即可使用，不需要安装、不需要注册、不产生任何网络请求， 所有数据保存在你自己的浏览器里。

1.2能力一览

02快速上手（3 分钟）

  1. 打开应用。双击 qingzhang.html，或访问部署好的在线地址。首次打开会自动生成 3 个账本、5 个个人账户、33 个分类和 7 条示例账单，方便你先看到成品效果。
  2. 确认在哪个账本记账。看左上角的账本胶囊，默认是「👤 个人账本」。点它可切换或新建账本。
  3. 点中间的 ＋ 记第一笔。用数字键盘输入金额 → 点一个二级分类 → 选付款账户 → 点「保存」。 保存后首页立刻出现这条账单，且所选账户余额自动扣减。
  4. 去「📊 报表」看一眼。折线图展示每天支出与收入，环形图展示钱花在哪些分类上。

03功能详解

以下每节按「用途 → 怎么操作 → 截图 → 实测表现 → 注意事项」展开，可按需跳读。

3.1首页：看我这个月花了多少

用途：一眼看清本月结余、支出、收入，并浏览每一笔账单。

  1. 顶部大数字是本月结余（收入 − 支出），正数带 +，负数带 −。
  2. 中间两个数字分别是本月支出与本月收入。
  3. 用月份左右两侧的 ‹ › 翻看历史月份；切到没有账单的月份会显示「本月还没有账单」空状态。
  4. 下方的账单按日期分组，组标题右侧显示当天合计（红为支出、绿为收入）；「今天 / 昨天」会被自动识别成中文标签。
  5. 点击任意一条账单，进入账单详情（见 3.4）。
实测记录

初始数据显示「2026年10月 / 本月结余 +5,769.00 / 支出 6,231.00 / 收入 12,000.00」，账单分为 5 个日期组、共 7 条。 点击 › 切到 11 月后出现空状态，点 ‹ 回到 10 月，账单数量与合计完全恢复。

3.2记一笔 · 支出

用途：记录一次花钱，并让它自动从对应账户余额里扣掉。

  1. 点底部中间的 ＋，弹出「记一笔」面板；默认停在「支出」（红色）。
  2. 输入金额：用屏幕数字键盘依次点按。支持小数点（.）、退格（⌫）； 左侧 ¥ 后的大数字就是当前金额，例如依次点 1、2、8 得到 128.00。
  3. 选分类：先点一级分类页签（如「餐饮」），再从下方图标网格里点二级分类（如「晚餐」）； 选中的格子会变成浅绿底并加粗。点「全部」可回到一级列表。
  4. 选账户：在「账户」区域点选付款的账户（现金／支付宝／微信钱包…），被选中的按钮为青色描边。
  5. 写备注（可选）：输入框里可直接打字；下方会自动列出你过去用得最多的备注，点一下即可复用。
  6. 改日期（可选）：面板底部的日期框默认今天，可改成补记的日期。
  7. 点右上角「保存」，或点键盘右下角的 ✓。保存后页面回到首页，新账单出现在最上方，并弹出「已保存」提示。
实测记录

键盘连续输入 1、2、8 → 显示 128.00；按一次 ⌫ → 12.00； 再输 8 并点 .、5 → 128.50。
选「餐饮 → 晚餐」后该格子高亮，页签自动落在「餐饮」上；选「支付宝」后账户按钮描边变色。 保存后：账单 7 → 8 条，支付宝 5,000.00 → 4,872.00，本月支出 6,231.00 → 6,359.00。

小技巧

键盘右侧四个功能键：📅 对应下方日期框、📝 直接把光标跳到备注、 ✓ 相当于「保存」；🖼 为图片凭证入口，当前版本仅提示「图片上传功能演示版未启用」。

3.3记一笔 · 收入与退款关联

用途：记录工资、兼职、红包等进账；买完东西退款时，把退款挂到原来那笔支出上，方便对账。

  1. 打开「记一笔」后，先点左上角的「收入」，金额区数字由红转绿。
  2. 此时分类面板会自动切换成收入分类（工资 / 兼职 / 理财 / 红包 / 退款 / 其他），选一个即可。
  3. 如果是退款：在「关联原账单」区域点选本月某笔支出，系统会自动填入该笔金额、付款账户， 并把备注写成「退款：原备注」。再点一次可取消关联。
  4. 点「保存」。收入会增加所选账户的余额。
实测记录

切到收入后分类页签变为「全部 / 💼 工资 / ✍️ 兼职 / 📈 理财 / 🧧 红包 / ↩️ 退款 / 💵 其他」。 点关联列表第一条（2026-10-14 的 18.00 元支出）后，金额自动变为 18.00， 备注自动变为「退款：豆浆油条」，被选中的候选项描边高亮；保存后该账单带有 refundOf 关联标记。

注意

关联原账单只自动带金额、账户和备注，不会自动带分类。退款场景建议在分类里手动选「↩️ 退款」， 这样报表里退款与正常收入能分开统计。

3.4账单详情：查看 / 修改 / 删除

用途：核对某笔账单的完整信息，或修正记错的金额、分类、账户、备注。

  1. 在首页（或搜索结果、日历）里点一条账单，弹出账单详情：大字金额、类型、分类、账户、日期、备注， 若有关联原账单还会显示可点击的跳转项。
  2. 点「✏️ 修改」进入编辑：面板标题变为「修改账单」，金额、分类、账户、日期、备注全部预填。
  3. 改完点「保存」。系统会先撤销原账单对余额的影响，再按新值重新计算， 因此账户余额只按差额变动，账单本身是「原地更新」（id 不变、不会多出一条）。
  4. 点「🗑 删除」，弹出红色二次确认「删除该账单？账户余额会同步回退」，确认后删除并把余额还原。
实测记录

把一笔 18.00 元的收入改为 666.00 元：保存后账单总量不变（9 条，未新增），该账单 id 未变， 关联账户余额按差额 +648 变动（4,890 → 5,538）。删除时账单数 9 → 8，账户余额同步回退。

余额联动规则

支出：保存时从账户扣减，删除时加回；收入：保存时增加，删除时扣回； 修改：先反向冲销旧值，再套用新值，等价于「只调整差额」。

3.5搜索账单

用途：在一个月几十上百条记录里快速找到某笔账。

  1. 点顶栏的 🔍，弹出「搜索账单」面板。
  2. 输入关键词。搜索范围包含备注、分类名（含二级）、账户名、金额、日期、类型，边输边出结果。
  3. 结果按日期倒序列出，带「找到 N 条」提示；最多展示 60 条。
  4. 点任意结果直接进入账单详情，搜索面板会自动收起。
实测记录

搜「餐」返回 4 条（晚餐、午餐、早餐、奶茶咖啡）；搜「128」按金额命中； 输入不存在的关键词时显示空状态并提示「换个关键词试试」。

注意

搜索只覆盖当前账本，不跨账本检索。要找家庭账本的记录，请先切换账本再搜。

3.6报表：趋势与分类占比

用途：看清「哪天花得多」「钱主要花在哪些类别」。

  1. 点底部「📊 报表」。上半部分是收支趋势：横轴为当月 1–31 日， 红线为支出、绿线为收入，带面积填充与图例。
  2. 下半部分是分类占比环形图：圆环中心显示当月总支出，下方列出各分类的金额与百分比。
  3. 点环形图上方的「一级 / 二级」切换粒度：一级看「餐饮／交通」这类大类，二级细到「早餐／午餐」。
  4. 报表月份跟随首页选择的月份，两边始终一致。
实测记录

一级粒度下统计出 4 行，首行为「🏠 居家 5,800.00 / 91.2%」；切到二级后变为 7 行。 折线图与环形图均为内置 SVG 绘制，无外部图表库，断网也能正常显示。

注意

环形图只统计支出，收入不参与占比；某月没有支出时图表区为空并提示「当月无支出」。

3.7资产：账户余额与净资产

用途：管理现金、支付宝、微信、银行卡、信用卡等账户，随时知道「我到底有多少钱」。

  1. 点底部「💰 资产」。顶部卡片显示净资产 / 总资产 / 总负债， 净资产 = 总资产 − 总负债（余额为负的账户计入负债，例如信用卡）。
  2. 下方按「资产账户」「负债账户」分组列出所有账户及余额，点任意账户进入编辑。
  3. 新增账户：点「资产账户」右侧的 ＋，填写账户名称、图标、类型、初始余额。
  4. 图标与类型都是「可下拉、也可手输」的组合框：点右侧 ▾ 展开 17 个图标 / 6 个支付方式预设，也可以直接键入新值（例如类型写「数字人民币」「美团月付」）。
  5. 计入总资产开关：默认打开。关掉后该账户只做记录，不参与净资产计算（适合「代管」「借出」类账户）。
  6. 编辑 / 删除：点已有账户即可改名称、余额、开关；编辑面板底部有红色「🗑 删除该账户」， 删除前会二次确认，并提示关联了多少笔账单。
实测记录

新增账户「数字人民币」，图标 🪙、类型手输「数字人民币」、余额 300： 账户数 5 → 6，类型字段完整保留自定义值。把它余额改为 1,234.50 后列表立即显示「+1,234.50」。 删除该账户时弹确认「删除账户"数字人民币"？」，确认后账户数回到 5。

注意

删除账户不会删除关联账单，这些账单会显示为「未选账户」，金额与记录仍然保留。 关闭「计入总资产」的账户，其余额变动不会影响净资产数字。

3.8预算：给花钱设一条线

用途：设定月度总预算与分类预算，超支时首页直接预警。所有账本（个人、家庭、旅行以及新建账本）都能单独设置，互不影响。

  1. 进入「👤 我的 → 🎯 预算」（首页预算卡右上角的「新增」/「修改」也能进）。
  2. 填月度总预算，例如 1000；填 0 表示不设预算。
  3. 在分类预算区域点「＋ 新增分类预算」：从已有分类里挑一个加进列表，或点「＋ 新建自定义分类」直接造一个新类别（如「宠物开销」，建好后记账时也能选到）。
  4. 新建分类时，图标栏点「选择 ▾」会展开图标库（餐饮 / 交通 / 购物 / 居家 / 娱乐 / 医疗 / 学习 / 人情 / 宠物 / 通讯 / 旅行 / 其他，共 12 类 108 个 Emoji），点一个即自动填入；也可以不用图标库，直接粘贴自己的 Emoji。
  5. 列表每行右侧有两个按钮：铅笔修改分类名（记账里的分类名会一起变）、垃圾桶把这条分类预算移出列表。填好金额点「保存」才生效，点「关闭」则本次增删都不算。
  6. 「预算结余自动转入下月」打开后，上月没花完的额度会滚到本月，首页卡片会标注「含结转 X」。
  7. 点「保存」。回到首页即可看到预算卡：总预算进度条 + 各分类进度条。
实测记录

设总预算 1,000、餐饮 300、交通 200，并打开结转：首页显示 「总预算（含结转 1,000.00）6,359.00 / 2,000.00　已超支 4,359.00」，餐饮行显示「431.00 / 300.00」进度条转红。 各分类预算写入 budgets[l1].categories，刷新后仍然保留。

颜色规则

进度条已用比例 < 80% 为青色；≥ 80% 转为橙色（提醒）；≥ 100% 转为红色并显示「已超支 X」。 预算只是提醒，不会阻止你继续记账。

3.9日历：按天回看

用途：用月历的视角看「哪些天有收支」，并快速查看某一天的明细。

  1. 点顶栏的 📅（或「我的 → 日历」）打开日历视图。
  2. 月历中，当天用青色圆角块标出；有支出的日期下方显示红点，只有收入则显示绿点。
  3. 点某个日期，下方卡片显示该日账单明细，点明细同样可进入账单详情。
  4. 用 ‹ › 翻月；右上角「回到今天」一键跳回当月并选中今天。
实测记录

2026 年 10 月渲染出 35 个格子，其中 6 天带收支圆点；点击 10-07 后下方正确列出当日账单； 翻到 9 月再点「回到今天」能准确回到 2026年10月。

3.10账本管理

用途：把「个人」「家庭」「旅行」「装修」等不同场景的账分开，互不干扰。

  1. 点左上角账本胶囊（如「👤 个人账本 ⌄」）打开账本列表，当前账本后打勾 ✓。
  2. 切换：点任意其他账本，顶栏、账户、分类、账单、预算会整体切换。
  3. 新建：点右上角「＋ 新建」，填名称、图标（Emoji）、币种符号，保存后出现在列表里。
  4. 修改：点某一行的铅笔图标（或点当前账本那一行），可改名、换图标、改币种符号与排序。
  5. 删除：点某一行的垃圾桶图标，或在编辑弹窗底部点「删除这个账本」，二次确认后删除；该账本下的账单、账户、分类与预算会一起清空。
实测记录

注意

删除账本不可恢复：该账本下的账单、账户、分类与预算会一起清掉。删除前建议先在「我的 → 导出」存一份 JSON 备份。系统强制至少保留一个账本，只剩一个时删除入口会自动隐藏。

  4. 新建二级分类：点某个一级分类下方的「＋ 添加二级分类」，或新建时在「父分类」里选上级。

用途：备份数据、迁移到其他设备，或把账单交给 Excel 做进一步分析。

导出

  2. 选格式：JSON 全量 备份所有数据（账本、账户、分类、预算、账单）， CSV 账单 只导出账单表格，方便 Excel 打开。

实测记录

3.14PIN 锁

用途：给应用加一道 4 位数字锁，防止手机被别人随手翻开。

  1. 进入「我的 → 🔒 设置 PIN 锁」，输入两次相同的 4 位数字，点「保存」。
  2. 刷新或重新打开页面时，先出现锁屏；输入正确 PIN 才会进入主界面。
  3. 输错会提示「PIN 错误」并清空已输入的圆点，可重试。
  4. 关闭 PIN：再次进入设置，先填「当前 PIN」，把「新 PIN / 确认 PIN」留空后保存。
实测记录

设 PIN 为 1234 后，存储里保存的是哈希值而非明文；刷新页面出现锁屏， 输入 0000 提示「PIN 错误」，输入 1234 正常解锁；再次进入设置并留空保存后，pinHash 被清为 null，锁屏不再出现。

注意

PIN 只是「防顺手一看」的轻量保护，数据本身没有加密，不要用它保存敏感信息。 忘记 PIN 将无法进入应用，只能清除该站点的浏览器数据（会同时清掉账本），因此设置前请先导出一份 JSON 备份。

04使用示例

下面四个场景串起了日常最常用的操作链路，可以照着做一遍熟悉手感。

4.1场景一：记一顿 128 元的午饭

  1. 点 ＋ → 键盘点 1 2 8，金额显示 128.00。
  2. 分类页签点「🍱 餐饮」→ 图标网格点「🍚 午餐」。
  3. 账户区点「🅰️ 支付宝」。
  4. 备注填「和同事聚餐」。
  5. 点「保存」。首页出现「午餐 · 餐饮-午餐 · 支付宝 · 和同事聚餐　−128.00」，支付宝余额 −128。

4.2场景二：工资到账 + 一笔退款

  1. ＋ → 切到「收入」 → 键盘输入 12000 → 分类选「💼 工资」→ 账户选「🏦 招行储蓄卡」→ 备注「10 月工资」→ 保存。
  2. 几天后早餐店退款 18 元：＋ → 收入 → 在「关联原账单」里点那笔 18 元的早餐支出。
  3. 金额与备注自动带出（备注为「退款：豆浆油条」），分类手动选「↩️ 退款」→ 保存。
  4. 打开这笔退款的详情，底部会显示「关联原账单 2026-10-14 · 18.00」，点它可跳到原来那笔支出核对。

4.3场景三：月末复盘 + 设下月预算

  1. 回首页看本月结余与预算卡，红色进度条表示已超支的类别。
  2. 进「📊 报表」，先看趋势图找出花得最猛的那几天，再切到「二级」看具体是哪些子类拉高了支出。
  3. 进「我的 → 预算」，把下月总预算与几个重点分类填上，打开「结余转入下月」把本月剩余额度滚过去。
  4. 进「我的 → 导出数据」导出一次 JSON，作为这个月的存档。

4.4场景四：换手机 / 换浏览器迁移数据

  1. 旧设备：「我的 → 导出数据」→ 选 JSON 全量 + 全部 → 下载，得到 qingzhang_2026-10-17.json。
  2. 把文件传到新设备（微信文件传输助手、网盘、数据线均可）。
  3. 新设备打开同一个 HTML（或同一个在线地址）→「我的 → 导入数据」→ 选择该文件 → 选「覆盖」→「导入」。
  4. 打开首页核对账单条数与账户余额，一致即迁移完成。
注意

迁移后两台设备各自独立，不会自动同步。若两边都在记账，再次「合并」导入即可把新增记录合并进来（相同 id 自动跳过）。

06常见问题与注意事项

6.1常见问题

问题解答
数据存在哪里？别人能看到吗？存在你当前浏览器的 localStorage 中，不上传服务器；同一台设备的其他浏览器、其他设备都看不到。
分享链接给别人，他们会看到我的账吗？不会。每个人打开都是自己浏览器里的一套数据，互不影响；但这也意味着不能多人共享同一个账本。
换手机怎么把账搬过去？旧设备导出 JSON → 新设备导入（覆盖）。参考场景 4.4。
金额记错了怎么办？点开账单 →「✏️ 修改」改数字即可，账户余额会自动按差额调整，不需要删了重记。
为什么账户余额和我实际不一致？账户余额 = 初始余额 + 收入 − 支出。若某笔账单记错了账户或删过账户，可在「资产」里编辑账户、直接改为实际余额。
导出 CSV 打开是乱码？文件已带 UTF-8 BOM，用 Excel / WPS 直接双击打开即可；若用记事本另存，请保持 UTF-8 编码。
忘记 PIN 了还能进吗？不能。只能清除该站点浏览器数据（会丢失账本）。因此设置 PIN 前务必备份 JSON。
预算超了还能继续记吗？能。预算只是提醒，不会拦截记账。
为什么首页和报表的数字一样，但和资产不同？首页/报表统计的是当月流水；资产页看的是账户余额与净资产，两者口径不同。
为什么分类里选不到「收入」分类？先点「记一笔」左上角的「收入」，分类面板会自动切换到收入分类；两套分类互不通用。

6.2十条注意事项

  1. 数据只在本机浏览器。清除浏览数据、换浏览器、换设备都看不到原数据，务必定期导出备份。
  2. 没有账号、没有云同步。同一链接在不同设备上是两份独立数据。
  3. 修改账单是「原地更新」。保存后不会多出一条，账户余额只按差额变动。
  4. 删除账单会回退余额。删除后账户余额会恢复到没记这笔之前的状态。
  5. 删除账户不删账单。相关账单会显示为「未选账户」，可进入详情重新指定账户。
  6. 删除一级分类会级联删除其二级分类。确认框会提示牵连数量，账单本身保留但变为「未分类」。
  7. 账本之间完全隔离。切换账本后账户、分类、账单、预算全部换一套，跨账本不会合并统计。
  8. 收入与支出分类各成体系。记账前先选类型，分类面板会自动跟着切换。
  9. 覆盖导入不可撤销。执行前先导出一次 JSON。
  10. 首次打开的 7 条示例账单可以直接删掉，账户初始余额也可在「资产」里改成自己的实际数字。
已知限制

① 不支持图片/票据上传（键盘 🖼 仅提示未启用）； ② 不支持转账（原版应用的转账功能在复刻版中已移除，历史转账账单仍可查看）； ③ 无账号体系与云同步； ④ 不支持支付宝 / 微信账单自动导入（仅支持本应用导出的 JSON/CSV）； ⑤ 账本支持新建、改名、删除（至少保留一个），删除会连带清空该账本的账单、账户、分类与预算； ⑥ 金额仅支持人民币符号展示，不处理多币种汇率换算。
