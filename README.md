# 小青账

一个**单文件、零依赖、纯本地**的轻量记账应用。双击 HTML 就能用，不需要装 App、不需要注册、不联网、没有后端 —— 数据全部存在浏览器的 `localStorage` 里。

👉 **在线体验 GitHub Pages**：**https://a369096433.github.io/qingzhang/**

👉 备用地址（WorkBuddy 托管，更新即时生效）：https://qingzhang-ledger-63298.app.workbuddy.host/

> 手机上打开链接后，用 Safari / Chrome 的「添加到主屏幕」，体验跟原生 App 基本一致（有独立图标、全屏、无地址栏）。
>
> 📖 [图文使用说明](https://a369096433.github.io/qingzhang/guide.html)
>
> ⓘ **如果打开后看到的还是旧界面**：GitHub Pages 会对页面做 10 分钟 CDN 缓存，刷新一次即可（电脑 Ctrl/Cmd+Shift+R，手机重开标签页）。
> 想确认自己看的是哪个版本：首页右下角「我的 → 关于小青账」，底部有版本号与日期。

## 功能

**记账**
- 支出 / 收入 / 转账三种类型，大键盘输入，支持备注、日期、账户
- 一级 + 二级分类（餐饮 › 午餐），分类可自己增删改
- 收支双向记账，退款可关联到原支出
- 长按任意账单弹出「编辑 / 再记一笔 / 删除」快捷面板

**多账本**
- 个人账本、家庭账本、项目账本……独立数据，右上角一键切换

**预算**
- 月度总预算 + 分类预算
- 进度条随使用率变色，超支时闪烁提醒

**报表**
- 收支趋势：平滑曲线 + 渐变面积，手指划过出十字线和当日金额气泡
- 分类占比：环形图，可切换一级 / 二级分类视角
- 每个分类的金额与占比列表

**资产**
- 多账户（现金 / 银行卡 / 支付宝 / 微信 / 信用卡……），支持负余额
- 净资产、总资产、总负债汇总，本月支出 TOP 5

**其它**
- 日历视图：月账单 / 年账单统计（支出、收入、结余、笔数、日均或月均、环比与同比、12 个月柱状图），下面逐条列出每笔记录
- 日历明细：月账单按「日」分段、年账单按「月」分段，可一键切平铺；首屏 30 条，超出用「加载更多」分批追加；点日历某天自动定位到当天分段
- 关键词搜索：分类名、账户名、备注、金额
- 数据导出 CSV / JSON、导入恢复
- 深色模式（暖黑纸感，不是死黑）
- PIN 码锁屏
- 明细页、关于页、使用说明

## 怎么用

**方式一：在线用**
打开上方链接即可，手机建议「添加到主屏幕」。

**方式二：本地用**
下载 `index.html`，双击用浏览器打开就行 —— 整个应用就是这一个文件。

---

## 数据与隐私

- 所有数据保存在你浏览器的 `localStorage`，**不上传任何服务器**
- 换设备、清缓存前请用「我的 → 导出数据」备份为 JSON
- 换浏览器数据不通用（不同浏览器的 localStorage 相互隔离）

## 技术说明

| 项 | 说明 |
|---|---|
| 形态 | 单个 HTML 文件，约 3800 行，无构建、无 npm 依赖 |
| 图标 | 26 个内联 SVG 线性图标（`ICON_PATHS` + `svgOf()`），不依赖图标字体 |
| 图表 | 手写 SVG：三次贝塞尔平滑曲线（控制点同 y 的水平切线，不过冲、不跌破零轴）、渐变面积、环形图、条形柱状图 |
| 设计 | 纸感手账风：米白纸底 + 暖描边 + 衬线数字；深色为暖黑 |
| 兼容 | 现代浏览器（Chrome / Edge / Safari / Firefox），移动端优先 |

## 发布与同步

| 入口 | 地址 | 更新方式 |
|---|---|---|
| GitHub Pages | https://a369096433.github.io/qingzhang/ | 推送到 `main` 后由 Actions 自动构建，约 1~2 分钟生效；CDN 另有 10 分钟缓存 |
| WorkBuddy 托管（备用） | https://qingzhang-ledger-63298.app.workbuddy.host/ | 重新发布后即时生效 |

> **两个平台必须同时更新**，只更一个会造成「同一版本两种内容」。GitHub Pages 是主入口，WorkBuddy 托管是备用入口，内容应当逐字节一致。

### 发版流程（每次改完都照此执行）

1. 改 `qingzhang.html`，再把关于页版本号改为新版本（`HTML 复刻版 · vX.Y · 日期`）。
2. `cp qingzhang.html index.html` —— 仓库跟踪的入口是 **`index.html`**，`qingzhang.html` 已被 `.gitignore` 忽略，不同步的话 Pages 拿不到新代码。
3. 提交并推送 `main`，**等 Actions 的 `pages build and deployment` 变成 `completed`**，再用 `curl -s https://a369096433.github.io/qingzhang/ | sha256sum` 与本地 `sha256sum index.html` 比对，一致才算生效（通常 1~2 分钟，CDN 另有 10 分钟缓存）。
4. 重新发布 WorkBuddy 托管（备份地址），同样比对 `sha256` 与字节数。
5. 顺手核对：README 顶部两个链接、`guide.html` 链接、以及页面里显示的版本号是否都指向新版本。

### 版本号规则

采用 `v主.次` 递增：

- **主版本 +1**：数据结构变更、需要迁移或可能影响已有账单的功能重做
- **次版本 +1**：新增功能、界面调整、缺陷修复等常规更新

版本号需要同时出现在三处，缺一不可（三处都改了才能一眼判断线上是不是最新）：

| 位置 | 形式 | 用途 |
|---|---|---|
| App「我的 → 关于小青账」 | `HTML 复刻版 · v1.1 · 2026-10-20` | 打开线上页面即可自查 |
| `README.md` 本节版本历史 | 表格一行 | 仓库里可追溯 |
| `guide.html` 封面 chip | `适用 App v1.1` | 说明书的适用版本 |
